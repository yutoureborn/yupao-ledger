# 芋炮小账本 Design System Master v0.3.4

## 产品定位
双人家庭财务工具。优先级：清晰、可靠、轻松、有生活气息。

## 设计旋钮
- Variance：4/10，保持克制与稳定
- Motion：3/10，仅保留有意义的微动效
- Density：7/10，适合桌面数据面板，但避免拥挤

## 色彩
- 主色：薄荷绿 `#7FAE9E`
- 主色深：`#557F71`
- 辅色：莫兰迪粉 `#CDA4A9`
- 页面背景：`#F4F7F4`
- 卡片：`#FFFEFC`
- 正文：`#2F3934`
- 次级文字：`#66716B`
- 边线：`#DFE7E1`

## 布局
- 桌面侧栏：224px
- 主内容：占满剩余宽度，最大 1520px
- 首页：12 列 Bento 网格
- 关键断点：1280 / 1024 / 720 / 420
- 禁止固定窄容器造成超宽屏大面积留白

## 交互
- 可点击目标最小 44×44px
- Hover 不能作为唯一反馈
- 过渡时间 150–240ms
- 仅动画 `transform` 与 `opacity`
- 支持 `prefers-reduced-motion`

## 组件
- 卡片统一 20–24px 圆角
- 卡片内部间距 20–24px
- 表单保留可见 label、字段级错误和 focus ring
- 图表必须同时使用文字、数值与颜色，不只依赖颜色

## 角色资产
角色作为信息辅助，不占据数据阅读主路径。首页大图使用 eager + WebP，其他场景 lazy load，容器预留固定空间避免 CLS。
