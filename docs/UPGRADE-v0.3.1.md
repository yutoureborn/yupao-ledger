# UPGRADE v0.3.1

## 本次升级内容
1. 新版“大芋头 + 小坦克”角色重做
2. 增加前端可落地 SVG 角色资产目录
3. 修复 PC 端支出扇形图/环形图显示异常问题
4. 调整 Hero、角色辅助区、统计排行的视觉细节

## 重点说明
### 1) 角色方案
- 旧版小坦克表情不稳定，且嘴巴表达破坏“沉稳角色设定”
- 新版改为：**左右双眼 + 炮管鼻子 + 无嘴**
- 大芋头保持可爱亲和，但减少花哨装饰

### 2) 图表修复
- 原实现使用 `circle + strokeDasharray`，在部分 PC 浏览器/布局组合下出现显示错位或圆环异常
- 新实现改为 **基于 SVG path 的 donut sector 绘制**，稳定性更高

## 升级后检查项
- 首页 Hero 角色显示
- 统计页“支出分类”在 PC 宽屏下是否稳定显示
- 预算提醒和设置安全页角色表现
- `public/illustrations/mascots/` 资产是否已随构建产出到 `dist/illustrations/mascots/`
