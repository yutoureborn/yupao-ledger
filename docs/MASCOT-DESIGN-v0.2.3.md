# 芋炮小账本：芋头与炮台角色升级设定稿

> 角色目标：可爱、拟人、生活化，但不幼儿化；角色服务于操作反馈，不抢财务信息的注意力。

## 1. 角色关系

### 芋头：生活账本小管家

- 性格：温柔、细心、可靠、略带慢热
- 职责：整理账本、展示总结、陪伴空状态、提示安全事项
- 核心道具：小账本、铅笔、盾牌或小锁
- 主色：芋泥紫、奶油白、淡粉腮红

### 炮台：元气记账小助手

- 性格：活泼、机灵、执行力强、偶尔得意
- 职责：快速记账、发射金币/收据、预算提醒、加载反馈
- 造型：圆润玩具炮台，不表现攻击和爆炸
- 主色：甜薯紫、淡灰紫、少量金色点缀

二者关系：

> 芋头负责“记清楚”，炮台负责“马上记”。

---

## 2. 造型升级

### 芋头

已在 SVG 中增加：

- 更清晰的眉眼和高光
- 双臂、小手与挥手动作
- 抱在胸前的小账本
- 账本随呼吸轻微起伏
- 安全状态的盾牌与小锁

避免：

- 过于复杂的叶片纹理
- 过大的腮红和婴儿化比例
- 每个页面使用不同画风

### 炮台

已在 SVG 中增加：

- 有高光的表情眼睛
- 可挥动的小机械臂
- 短炮口与圆形轮底
- 炮口轻微观察动作
- 成功时发射金币、票据或星光

避免：

- 火焰、爆炸、弹药
- 尖锐金属边缘
- 高频旋转或持续抖动

---

## 3. 状态与动作清单

| 状态 | 芋头动作 | 炮台动作 | 使用位置 |
|---|---|---|---|
| `idle` | 呼吸、眨眼、偶尔挥手 | 左右观察、挥手 | 首页欢迎、普通空闲 |
| `welcome` | 挥手迎接 | 轻抬炮口 | 登录成功、首次进入 |
| `empty` | 抱着空账本等待 | 从旁边探头 | 无账目、无搜索结果 |
| `success` | 举起账本/开心点头 | 发射金币和星光 | 记账成功、保存成功 |
| `summary` | 指向图表 | 弹出小票据 | 月度总结、统计页 |
| `warning` | 看向提示牌 | 举起叹号牌、轻晃 | 预算接近上限 |
| `safe` | 抱着盾牌/锁 | 在旁边守护 | 设置与安全管理 |
| `loading` | 低幅呼吸 | 炮口慢速观察 | 短时加载，不长时间占屏 |

## 4. 表情规范

推荐表情：

- 开心：弯眼、小幅张嘴
- 专注：眉毛轻压、看向账本
- 提醒：睁眼、嘴型收小，不做惊恐
- 安心：闭眼微笑、抱盾牌
- 空状态：平静等待，不做哭泣或负面责备

角色文案不能责备用户，例如不使用：

- “你又花超了”
- “怎么还没记账”
- “本月消费太夸张”

推荐：

- “这个分类已经花了不少，后面留意一下”
- “这里还没有记录，先记一笔试试吧”
- “这笔已经收进小账本”

---

## 5. 动画技术规范

当前生产实现：内联 SVG + CSS Animation。

原因：

- 不增加第三方动画运行时
- 体积小
- 可随主题调整
- 易于响应 `prefers-reduced-motion`
- 不需要外部网络资源

规范：

- SVG 角色组件统一封装在 `Mascot`
- 不在页面复制角色 SVG
- 待机动画低频、低幅
- 成功动画只播放一次或短时循环
- 角色动画不能阻挡按钮点击
- 装饰元素设置为非交互

---

## 6. 生产资产与概念图的边界

本轮概念视觉用于统一角色方向，不直接作为页面生产资源。生产页面继续使用代码内 SVG，避免：

- 大图增加首屏负担
- 多画风资产不统一
- 图片文字不可访问
- 后续修改动作需要重新生成整张图

1. 独立 SVG 角色资产目录
2. 角色表情与动作 Sprite
3. PWA 启动画面和图标统一
4. 月度总结分享图中的高质量静态角色
