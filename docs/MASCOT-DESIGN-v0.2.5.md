# 芋炮角色生产设定 v0.2.5

## 风格基线

角色采用拟人蔬菜插画方向：轮廓自然、表情夸张但不幼儿化、细线手脚、柔和纹理、轻量阴影。禁止继续使用无纹理的椭圆芋头和普通几何坦克。

## 芋头

- 身份：元气记账小助手。
- 主色：`#9B78CE`，深色 `#7654A4`，浅色 `#DCCEF2`。
- 造型：不规则芋头根茎、横向表皮纹理、两片叶子、大眼高光、细手脚。
- 动作：拿铅笔、抱账本、举收据、投金币、翻页。

## 炮台

- 身份：生活账本小管家。
- 主色：`#55775B`，深绿 `#3F5F49`，结构黑 `#26302C`。
- 造型：圆润玩具车体、短粗炮口、大黑轮、机械臂、绿色状态灯。
- 动作：归档账目、投影图表、弹出预算提示、展开安全盾牌。

## 关系

> 芋头把每一笔记进来，炮台把每一笔整理好。

## 技术约束

- 生产资源继续使用内联 SVG 和 CSS Animation。
- 不在首屏加载大尺寸角色 PNG。
- 所有循环动画受 `prefers-reduced-motion` 和应用内“轻动画”设置控制。
- 角色图层不能拦截点击。
