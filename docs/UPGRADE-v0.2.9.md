# v0.2.9 升级说明

## 升级目标
将“炮台”角色升级为 **坦克拟人形象**，并保持当前轻量 UI 的整体风格。

## 本次改动
1. `CannonCharacter` 改为坦克外形：
   - 圆润车身
   - 坦克炮塔
   - 履带底盘
   - 拟人眼睛、嘴巴、腮红
   - 绿 / 黄 / 黑三色体系
2. `LogoMark` 中的辅助角色同步替换为坦克小助手
3. 版本号更新到 `0.2.9`
4. Service Worker shell cache 更新到 `yupao-shell-v9`

## 数据影响
- 无数据库变更
- 无接口变更
- 无发票、收支、用户数据结构变更
