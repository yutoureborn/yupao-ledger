# UPGRADE v0.3.2

## 本次升级重点
这次不再继续对旧的扇形图模块做局部修补，而是**整体重构“钱花去了哪里 / 支出分类”模块**。

### 重构内容
1. 原旧版“环形图 + 列表”区域整体重做为三段式结构：
   - 顶部：摘要头部（总支出 / 分类数 / 单类均值）
   - 中部：稳定的 path donut 图 + 右侧摘要卡
   - 底部：完整分类排行列表
2. 图形绘制从 `circle + strokeDasharray` 改成 **SVG path 扇区绘制**，提升 PC 端稳定性
3. 调整卡片容器、分割线、间距和层级，减少空白和割裂感
4. 更新版本号到 `0.3.2`

## 影响范围
- 首页 Dashboard 中的“钱花去了哪里”
- 统计页中的“支出分类”
- 相关静态资源版本号、SW 版本号和测试断言

## 升级后建议检查
- PC 宽屏 1200px+ 下，图表是否居中且无重复空心圆
- 移动端 390px 左右宽度下，排名列表是否自然换行
- 查看全部分类按钮是否正常跳转
