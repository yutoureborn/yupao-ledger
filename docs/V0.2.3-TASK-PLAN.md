## 7. 发布步骤（用户操作）

### 7.1 上传补丁

在 GitHub 仓库：

```text
Add file → Upload files
```

上传补丁内文件并覆盖同名文件，提交到 `main`。

不要覆盖你现有的 `wrangler.jsonc`，因为其中包含真实 D1 Database ID。

### 7.2 等待 Workers Builds

```text
Cloudflare → Workers & Pages → yupao-ledger → Deployments
```

确认日志显示：

```text
yupao-ledger@0.2.3
27 tests
27 pass
Deploying ✓
```

### 7.3 清除旧页面缓存

部署后第一次打开：

- Windows：`Ctrl + Shift + R`
- PWA：完全关闭后重新打开
- 仍显示旧版时：站点设置 → 清除该站点缓存

### 7.4 验收

1. PC 打开首页，确认分类名称不再换行。
2. 缩窄浏览器，确认卡片自动转为纵向。
3. 手机打开统计页，确认无横向滚动。
4. 记一笔，确认成功角色动画正常。
5. 设置页修改密码，确认需要使用新密码重新登录旧设备。
