# GitHub 与官方实践参考

## UI/UX Skill

1. `nextlevelbuilder/ui-ux-pro-max-skill`
   - 用于设计系统、金融工具可读性、响应式和无障碍检查。
2. `hursh-shah/codex-design-skill`
   - 用于先明确视觉方向，再编码，避免无目标堆组件。
3. `vipulgupta2048/codex-skills` 中的 frontend-design
   - 用于减少常见 AI 紫色渐变、模板化 Hero 和无意义装饰。

本项目没有直接运行这些仓库的脚本，也没有引入未知依赖；仅采用其公开的设计工作流和检查项。

## 动画与性能

- Anime.js 官方仓库及 V4 WAAPI 文档：轻量、模块化、优先 transform/opacity。
- MDN content：preload、Web Performance、PWA 与缓存策略。
