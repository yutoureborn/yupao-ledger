# v0.3.9 升级说明

## 目标
减少记账时的文本输入，尽可能把高频操作改成直接选择，同时丰富支出分类。

## 移动端流程
普通支出默认只需要：

1. 输入金额
2. 点选常用分类
3. 确认默认账户与日期
4. 保存

低频字段不再默认展开。

### 分类
- 默认显示 6 个常用 / 最近分类
- “全部分类”打开 Bottom Sheet
- 支出分类按生活场景分组

### 账户
- Bottom Sheet 直接选择
- 自动记忆同一收支类型上次使用的账户

### 日期
- 今天
- 昨天
- 其他日期

### 商户 / 来源
- 自动读取近期交易中的商户
- 优先直接选择历史商户
- 只有新商户才进入输入模式
- 新商户会写入本机最近使用记录

### 备注
- 默认折叠
- 需要时点击“添加备注”展开

## PC 端
- 分类：分组下拉框
- 账户：下拉框
- 日期：今天 / 昨天 / 日期选择器
- 商户：历史建议 + 可输入
- 备注：折叠区域

## 新版支出分类
### 日常生活
餐饮、外卖、买菜、零食饮品、日用百货、水电燃气、通讯网络、订阅会员

### 居住家庭
房租房贷、物业费、家居家装、数码家电

### 交通出行
公共交通、打车、加油、停车、车辆养护、旅行

### 购物消费
服饰鞋包、美妆护肤、数码产品、网购

### 健康
医疗、药品、健身运动、保健护理

### 宠物
宠物食品、猫砂日用品、宠物医疗、宠物玩具

### 娱乐生活
娱乐、电影演出、兴趣爱好

### 人情社交
人情往来、礼物、红包

### 学习工作
学习培训、软件工具、办公用品

### 金融其他
保险、税费、银行手续费、其他支出

## 兼容性
不新增数据库 migration。Worker 在 bootstrap 时检查默认分类名称，仅补齐缺失分类：
- 不删除用户分类
- 不覆盖用户已有分类
- 不改变历史交易的 category_id
- 已归档的同名分类不会重复新增
