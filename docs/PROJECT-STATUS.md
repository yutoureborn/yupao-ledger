# 项目开发状态

> 对应开发计划：芋炮小账本 v1.1 动态交互版  
> 当前交付版本：MVP 0.1.0

## 已完成

### 产品与 UI

- 响应式手机、平板和桌面布局
- 首页、明细、记一笔、统计、账户、预算和设置页面
- 芋头与玩具炮台 SVG 角色
- 页面进入、按压、数字、进度条和图表动画
- 系统与手动减少动画模式
- 加载、空状态、错误、断网、提交和撤销反馈
- 简洁、可爱、低装饰密度的设计系统

### 动态业务功能

- 收入、支出和转账新增
- 交易编辑、软删除和恢复
- 交易搜索与条件筛选
- 账户新增、编辑和归档
- 分类新增和归档
- 月度总预算和分类预算
- 动态账户余额
- 本月收入、支出和结余
- 日趋势、分类占比和近六个月对比图表
- CSV 与 JSON 导出

### 服务端与数据

- Cloudflare Worker REST API
- Cloudflare Access JWT 验签
- 两个允许邮箱的二次白名单校验
- 自动创建家庭空间和成员映射
- D1 数据库 Migration
- 金额按整数“分”存储
- 家庭数据隔离
- 并发版本冲突检测
- 审计日志
- API 财务数据禁止缓存

### 工程化

- 本地 Node 22 + SQLite 开发服务器
- 本地演示数据和空账本模式
- PWA Manifest、Service Worker 和应用图标
- 无外部 CDN 运行依赖
- 自动构建与 API 测试
- D1 加密备份与谨慎恢复脚本
- 手动 Cloudflare 部署文档

## 本次不包含

- 由开发方替用户创建 Cloudflare 资源或执行线上部署
- 银行自动同步
- 票据 OCR
- 原生移动端应用
- 离线写入队列
- WebSocket 实时推送
- 复杂拆分账单和信用卡账期

## 部署前待用户填写

- D1 database ID
- 两个正式邮箱
- Cloudflare Access 团队域名
- Access 应用 AUD
- 正式自定义域名
- 可选 R2 Bucket 与备份密码

## 建议上线验收

1. 两名成员分别登录一次。
2. 成员 A 新增一笔交易，成员 B 刷新后确认可见。
3. 新增一次账户转账，确认不进入收入和支出统计。
4. 修改、删除并撤销一笔交易。
5. 检查手机端键盘、底部导航和弹窗。
6. 检查 PWA 安装后仍需经过 Access。
7. 执行一次加密备份，并在非正式环境演练解密恢复。
