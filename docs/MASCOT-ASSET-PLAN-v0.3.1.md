# 芋炮小账本角色资产方案 v0.3.1

## 目标
本次升级把“大芋头 + 小坦克”统一成可直接前端落地的矢量资产方案，避免继续依赖 JPG 截图素材。

## 设计原则
- **生活气息**：表情友好、轻松、不幼稚
- **克制可爱**：薄荷绿 + 莫兰迪粉/紫为主，避免过度装饰
- **前端可用**：优先 SVG，可直接用于 Web / PWA / H5
- **角色分工明确**：
  - 大芋头：活泼、负责“快速记账”
  - 小坦克：沉稳、负责“整理、提醒、安全、统计”

## 资产目录
`public/illustrations/mascots/`

### 单体资产
1. `taro-front-v031.svg`
   - 用途：空状态、记录成功、欢迎/引导
2. `tank-front-v031.svg`
   - 用途：统计、安全、预算提醒、整理页

### 双角色资产
3. `hero-duo-v031.svg`
   - 用途：首页 Hero、品牌头图
4. `duo-summary-v031.svg`
   - 用途：统计总览、图表页引导
5. `duo-warning-v031.svg`
   - 用途：预算提醒、超支提醒
6. `tank-safe-v031.svg`
   - 用途：安全中心、设置页、登录安全提示

## 推荐落地方式
### A. 运行时组件
- 现阶段页面主流程继续使用 `src/frontend/app.tsx` 中的内联 SVG 角色组件，保证动效和状态切换最稳定。

### B. 资源交付
- 设计/开发协作、后续多端复用时，直接引用上述 SVG 文件。
- 如需导出 PNG，建议从 SVG 统一导出 1x / 2x / 3x，不要反向从 JPG 截图裁切。

## 状态建议
| 状态 | 推荐角色 | 说明 |
|---|---|---|
| 首页 Hero | 大芋头 + 小坦克 | 主品牌组合 |
| 记一笔 | 大芋头主导 | 铅笔/记账板强化“快速记录” |
| 统计 | 小坦克主导 | 炮管作鼻子，双眼稳定表达 |
| 预算提醒 | 小坦克 + 提醒标记 | 不使用嘴巴，保留沉稳感 |
| 安全中心 | 小坦克 + 盾牌 | 强化守护感 |
| 空状态 | 大芋头 | 更温和更亲和 |

## 命名规范
- 文件：`角色-场景-v版本.svg`
- 例如：`hero-duo-v031.svg`
- 不建议继续使用含糊命名如 `imagegen.png`、`hero-duo-new2`

## 后续可扩展

## 这次相对上一版的关键变化
- 小坦克去掉嘴巴，仅保留“炮管作鼻子 + 左右双眼”
- 大芋头表情更圆润，整体更接近当前确认通过的品牌方向
- 角色颜色更收敛，黑色轮组、绿色主体、黄色结构更统一
- 从“截图式角色图”升级为“可维护的矢量资产”
