# 芋炮小账本：芋头与炮台角色升级设定稿

> 文档版本：v0.2.4  
> 更新说明：互换芋头与炮台的角色职责，并同步调整配色、道具、动作和应用场景。  
> 角色目标：可爱、拟人、生活化，但不幼儿化；角色服务于操作反馈，不抢财务信息的注意力。

---

## 1. 角色关系

### 芋头：元气记账小助手

- **性格**：活泼、机灵、行动力强、偶尔有一点小得意
- **职责**：
  - 引导快速记账
  - 完成新增、保存等操作反馈
  - 提醒待记录事项
  - 在加载和空状态中提供陪伴
  - 用拟人动作表达“马上行动”
- **核心道具**：
  - 小铅笔
  - 迷你收据
  - 金币袋
  - 快捷记账卡片
- **主色**：
  - 明显芋泥紫
  - 深芋紫阴影
  - 奶油白高光
  - 淡粉腮红
- **推荐色值**：
  - 主色：`#A78BDA`
  - 深色：`#8061B5`
  - 浅色：`#D9C8F2`
  - 面部高光：`#F5EEFF`
  - 腮红：`#E9B7D4`

芋头不是安静地站在旁边，而是更主动地参与操作：

- 用户准备记账时，芋头拿起铅笔
- 输入金额后，芋头看向数字并轻轻点头
- 保存成功时，芋头举起收据或金币
- 连续记账时，芋头快速翻到下一页
- 空状态时，芋头主动邀请用户“先记一笔”

---

### 炮台：生活账本小管家

- **性格**：沉稳、细心、可靠、有秩序感，偶尔表现出机械式认真
- **职责**：
  - 整理账本
  - 展示统计与月度总结
  - 提供预算和异常提醒
  - 守护账号与数据安全
  - 在账户、统计、设置页面承担信息讲解
- **核心道具**：
  - 投影式图表
  - 分类卡片
  - 盾牌与小锁
  - 小型提示灯
  - 账目归档盒
- **造型**：
  - 圆润的玩具机械炮台
  - 炮口更像投影仪或提示发射器
  - 不表现攻击、火焰、爆炸和弹药
- **主色**：
  - 苔绿 / 墨绿
  - 黑灰结构件
  - 少量亮绿提示灯
- **推荐色值**：
  - 主绿色：`#4F7C64`
  - 深绿色：`#355646`
  - 黑灰：`#252A28`
  - 金属绿灰：`#789080`
  - 亮绿提示：`#9ED36A`

炮台的“发射”不用于表现快速行动，而是用于整理和讲解：

- 发射一张分类卡片
- 投影本月收支图表
- 弹出预算提示牌
- 在安全设置页展开盾牌
- 完成月度总结后盖上“已整理”印章

---

### 二者关系

> **芋头负责“马上记”，炮台负责“整理好”。**

角色关系不采用上下级结构，而是家庭账本中的两位搭档：

- 芋头把生活中的每一笔快速收进来
- 炮台把收进来的记录分类、统计并守护好
- 芋头偏感性与行动
- 炮台偏理性与秩序
- 两者共同出现时，由芋头发起动作，炮台完成整理反馈

推荐互动：

1. 芋头递出一张收据，炮台将其吸入归档槽
2. 芋头投入一枚金币，炮台投影最新余额
3. 芋头快速写下一笔，炮台亮起绿色“已整理”提示灯
4. 芋头发现预算接近上限，炮台弹出温和提醒卡
5. 月度总结时，芋头坐在炮台旁边查看投影图表

## 2. 造型升级

### 芋头

造型重点：

- 整体以明显芋泥紫为主，避免再次偏成粉白色角色
- 身体圆润，但保留清晰的小手与小脚
- 顶部叶片保持简洁，不做复杂植物纹理
- 面部表情更灵活，增强行动型角色气质
- 服装或背带中可以加入少量奶油白与深紫层次

建议新增：

- 可握住铅笔的小手
- 腰间小收据袋
- 可翻页的小账本
- 成功时举起金币或打勾卡片
- 连续记账时的小跑步动作
- 输入金额时轻轻前倾观察

避免：

- 过大的腮红
- 过度婴儿化比例
- 高频跳跃
- 每次输入都出现大幅动画
- 与炮台使用相同的沉稳动作节奏

### 炮台

造型重点：

- 绿黑配色必须明确，不再使用紫色主体
- 以墨绿机身配合黑灰结构件
- 炮口短而圆，表现为投影器或卡片发射器
- 机械底座稳重，避免像战斗车辆
- 亮绿色只用于状态灯和少量高光

建议新增：

- 可投影图表的炮口
- 两侧机械臂，可整理卡片或举盾牌
- 黑灰轮底或圆形稳定底座
- 正面小显示屏，可出现勾号、锁、预算符号
- 分类整理时的卡片归档槽
- 安全状态的机械护盾

避免：

- 火焰
- 爆炸
- 弹药
- 枪械瞄准动作
- 尖锐金属边缘
- 大面积荧光绿
- 高频旋转或持续震动

## 3. 状态与动作清单

| 状态 | 芋头动作 | 炮台动作 | 使用位置 |
|---|---|---|---|
| `idle` | 呼吸、眨眼、轻轻晃动铅笔 | 状态灯呼吸、低幅观察 | 首页欢迎、普通空闲 |
| `welcome` | 挥手并递出记账卡 | 点亮显示屏、展开今日概览 | 登录成功、首次进入 |
| `quick-add` | 拿起铅笔、前倾查看金额 | 在旁边打开归档槽 | 记一笔页面 |
| `empty` | 主动举起“先记一笔”卡片 | 保持待机并打开空归档盒 | 无账目、无搜索结果 |
| `success` | 举起金币或收据、开心点头 | 吸入记录并亮起绿色勾号 | 记账成功、保存成功 |
| `continuous` | 快速翻页并准备下一笔 | 归档上一笔后恢复待机 | 连续记账 |
| `summary` | 坐在旁边认真查看 | 投影图表、弹出分类卡片 | 月度总结、统计页 |
| `warning` | 看向炮台提示并轻轻停笔 | 弹出叹号卡、状态灯变为柔和黄绿 | 预算接近上限 |
| `safe` | 抱着自己的小账本靠近炮台 | 展开机械护盾与小锁 | 设置与安全管理 |
| `loading` | 小幅翻动纸页或等待 | 状态灯逐点亮起，不旋转炮口 | 短时加载 |
| `error` | 停笔、疑惑看向炮台 | 显示屏出现温和重试图标 | 网络或保存失败 |
| `done` | 合上账本并比出完成手势 | 盖上“已整理”印章 | 月度完成、导出完成 |

## 4. 页面职责分配

### 芋头主导的场景

- 登录后的欢迎
- 快速记账入口
- 新增收入、支出和转账
- 连续记账
- 保存成功
- 空状态引导
- 首次使用提示
- 轻量操作教学

### 炮台主导的场景

- 首页数据总览
- 收支趋势图
- 分类占比
- 月度总结
- 预算进度
- 账户余额
- 数据导出
- 安全设置
- 会话与恢复码管理
- 错误诊断和数据异常提醒

### 双角色共同出现的场景

双角色不应在每个页面同时出现，仅用于关键节点：

- 初始化成功
- 首次完成记账
- 月度总结完成
- 数据恢复成功
- 安全设置完成
- 年度回顾

共同出现时：

- 芋头在前方或动作起点
- 炮台在后方或结果展示区域
- 芋头负责产生动作
- 炮台负责展示结构化反馈

## 5. 表情规范

### 芋头表情

- **开心**：弯眼、小幅张嘴，动作更主动
- **专注**：看向金额或账本，眉毛轻轻下压
- **得意**：完成记账后轻抬眉，但不过度夸张
- **疑惑**：网络失败时轻歪头
- **等待**：平静眨眼，不表现焦躁

### 炮台表情与机械反馈

- **正常**：正面显示屏为柔和绿色圆点
- **整理中**：状态灯依次点亮
- **完成**：显示绿色勾号
- **提醒**：显示柔和叹号，不闪红灯
- **安全**：显示小锁和盾牌
- **错误**：显示重试符号，不做警报或剧烈震动

角色文案不能责备用户，例如不使用：

- “你又花超了”
- “怎么还没记账”
- “本月消费太夸张”

推荐：

- “芋头已经把这笔记下啦”
- “炮台正在帮你整理”
- “这笔已经收进小账本”
- “这个分类已经花了不少，后面留意一下”
- “这里还没有记录，先让芋头记一笔吧”
- “炮台已经整理好本月数据”

## 6. 动画节奏

### 芋头

芋头动作偏轻快：

- 按钮反馈：`140–220ms`
- 拿笔 / 点头：`260–420ms`
- 保存成功：`500–800ms`
- 连续记账翻页：`350–600ms`
- 待机循环：`4–6s`

### 炮台

炮台动作偏稳定：

- 状态灯切换：`180–320ms`
- 卡片归档：`350–600ms`
- 图表投影：`500–900ms`
- 安全盾牌展开：`450–750ms`
- 待机循环：`6–9s`

两者同时出现时：

1. 芋头动作先发生
2. 间隔 `80–160ms`
3. 炮台开始整理反馈
4. 总时长控制在 `900ms` 内

## 7. 动画技术规范

当前生产实现：

```text
内联 SVG + CSS Animation
```

后续继续保持轻量方案：

- 角色 SVG 统一封装
- 芋头与炮台分别拆分为独立图层
- 动作通过 `transform` 和 `opacity` 实现
- 不在页面复制整段 SVG
- 不依赖第三方在线动画资源
- 不让角色动画阻挡按钮点击
- 装饰图层设置为非交互
- 首屏只加载当前需要的角色状态

必须支持：

```css
@media (prefers-reduced-motion: reduce)
```

减少动态模式下：

- 关闭待机循环
- 停止挥手、翻页和炮口观察
- 图表投影改为快速淡入
- 成功动作改为静态勾号
- 保留必要的加载和错误状态信息

## 10. 最终角色定义

### 芋头

> 芋头是负责把生活立即记下来的元气小助手。它主动、轻快、愿意行动，用芋泥紫和拟人动作降低记账的操作压力。

### 炮台

> 炮台是负责把每笔记录整理清楚、展示明白并安全守护好的机械小管家。它稳定、有秩序，以绿黑配色建立可靠感。

### 核心关系

> **芋头把每一笔记进来，炮台把每一笔整理好。**
