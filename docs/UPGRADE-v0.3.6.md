# v0.3.6 升级说明

## 升级定位
这不是纯视觉微调，而是继续把三个关键页面往“可交付产品级”方向推进：

1. 首页
2. 收支明细页
3. 收支统计页

## 本次变更

### 1. 命名统一
- 保留坦克造型
- 对外命名统一为：**小炮台**
- 所有页面文案、提示语、角色描述同步调整

### 2. 首页优化
- Hero 卡片视觉层次提升
- 摘要卡与 Bento 卡片阴影、边界、留白优化
- 最近记录与发票模块更规整

### 3. 明细页重构
- 新增顶部月度概览卡
- 新增四个摘要指标：记录数 / 支出合计 / 收入合计 / 转账记录
- 筛选区和结果区拆分，更符合真实产品使用逻辑
- 列表卡片更规整，阅读节奏更清楚

### 4. 统计页优化
- 新增统计摘要卡带
- 支出分类 / 预算 / 趋势 / 月度对比层级更清晰
- 页面整体更接近正式分析后台的成品态

## 不涉及内容
- 不新增 D1 migration
- 不改认证逻辑
- 不改 API 行为
- 不动已有用户数据
