# 芋炮小账本 v0.3.0 设计系统

## 设计定位

**生活气息、简单可爱、清淡克制。**

界面不是儿童手账，也不是企业财务后台。核心感受是：两个人在安静、轻松地记录共同生活。

## 色彩

- 薄荷绿主色：`#7FAE9E`
- 薄荷深色：`#557F71`
- 薄荷浅底：`#E5F1EB`
- 莫兰迪粉：`#CDA4A9`
- 粉色浅底：`#F3E6E8`
- 页面背景：`#F5F8F5`
- 主文字：`#303834`
- 次文字：`#68736D`

## 角色层级

- **大芋头**：面积更大、动作更活泼，负责快速记账和正向反馈。
- **小坦克**：面积更小、动作更慢，负责整理、统计、预算与安全。

## 组件原则

- 卡片只保留一层轻阴影。
- 主按钮使用薄荷深色，次按钮使用莫兰迪粉浅底。
- 辅助文字不能使用低对比粉灰。
- 图表先保证数值和分类可读，再使用柔和配色。
- 角色只出现在关键场景，不覆盖财务信息。
