# 芋炮小账本 v0.2.6 图表重构规范

## 1. 当前问题

旧图表主要问题：

1. 圆环与分类列表在窄卡片中容易失衡。
2. 分类色直接来自用户设置，整体画面不统一。
3. 单分类时圆环过空，列表信息弱。
4. 图表与新暖色 UI 缺少统一关系。

## 2. 新结构

```text
圆环图
本月支出金额
分类数量
----------------
分类排行列表
查看全部分类
```

PC 完整统计页：

```text
[圆环图] [分类排行]
```

首页右栏：

```text
[圆环图]
[分类排行]
```

移动端：

```text
[圆环图]
[分类排行纵向列表]
```

## 3. 暖色图表色板

```text
#9B78CE 芋泥紫
#E8845E 珊瑚橙
#7FA66B 苔绿
#F0B653 暖黄
#6D9FA7 灰蓝
#C982A6 柔粉
#B88858 暖棕
```

图表不再直接使用分类自定义颜色，以确保统计页视觉统一；分类管理中的颜色仍用于分类标签和账户卡片。

## 4. 圆环

- 线宽：28
- 端点：圆角
- 中心底色：奶油白
- 中心文字：本月支出 + 金额
- 单分类仍保留完整圆环
- 分段间使用小间隔

## 5. 分类列表

固定列：

```text
排名 | 图标 | 名称+进度 | 金额
```

- 名称单行省略
- 百分比与名称同一行
- 金额固定右对齐
- 进度条高度 7px
- 移动端隐藏排名列

## 6. 动画

- 圆环首次进入：460ms
- 进度条首次进入：650ms
- 不做循环动画
- 减少动态模式下直接显示最终状态
