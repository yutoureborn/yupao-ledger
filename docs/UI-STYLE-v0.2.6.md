# 芋炮小账本 v0.2.6 UI 风格规范

> 设计方向：奶油暖色系 + 大圆角卡片 + 生活方式插画 + 轻量数据可视化  
> 适用终端：PC、平板、移动端 PWA  
> 参考原则：吸收参考图的版式和视觉节奏，不复制具体品牌、图标或业务结构。

## 1. 设计目标

1. 从“可爱后台”升级为“生活方式家庭账本”。
2. 降低财务工具的冷硬感，同时保留金额、趋势和预算的可读性。
3. UI、静态角色、图表使用同一套暖色语言。
4. 减少复杂角色动画，避免动画还原质量拉低整体完成度。
5. PC 与移动端采用不同信息密度，不做简单等比例缩放。

## 2. 视觉关键词

- 奶油暖色
- 杏橙主导航
- 柔和米白背景
- 生活化插画
- 大圆角
- 轻阴影
- 稳定留白
- 少量芋泥紫和苔绿色点缀

避免：

- 霓虹渐变
- 透明玻璃叠层
- 过多发光
- 复杂粒子
- 每个卡片使用不同插画
- 角色高频动画

配色比例：

- 10% 苔绿
- 5% 金黄、灰蓝等图表辅助色

## 4. PC 布局

### 4.1 左侧导航

- 固定宽度：216px
- 背景：杏橙渐变
- 普通菜单：白色 78% 透明度
- 选中菜单：奶油白卡片
- 不显示左侧竖条，避免后台系统感
- 底部成员信息使用半透明暖色卡片

### 4.2 主内容区

- 最大宽度：1240px
- 页面左右间距：32px
- 首页主网格：左侧 1.52fr，右侧 0.82fr
- 卡片间距：18px
- 卡片圆角：24px
- Hero 圆角：30px

### 4.3 首页结构

1. 欢迎标题与月份切换
2. 暖杏色 Hero 插画卡
3. 四个柔和彩色摘要卡
4. 左栏：收支趋势、最近记录
5. 右栏：分类支出、预算进度

## 5. 移动端布局

- 顶部固定品牌栏
- 底部五项导航
- Hero 文字占 68%～76%，插画置右下
- 摘要卡两列排列
- 图表卡全部纵向
- 分类列表金额固定右对齐
- 页面左右间距 12～16px
- 禁止横向滚动

## 6. 组件规范

### 卡片

- 默认：奶油白
- 信息卡：绿色、桃橙、淡紫、浅黄四组柔色
- 卡片内部不使用多层边框
- hover 只做 1～2px 上移，不做明显翻转

### 按钮

- 主按钮：杏橙渐变
- 次按钮：淡桃色背景
- Hero 内主按钮：奶油白
- 按压反馈保留，持续时间 120～180ms

### 表单

- 背景：奶油白
- 聚焦边框：杏橙
- 聚焦光环：杏橙 11% 透明度
- 分类胶囊使用柔和米杏色

## 7. 动效原则

保留：

- 页面淡入
- 按钮按压
- 进度条与图表首次加载
- Toast 和 Modal 过渡
- 静态插画极轻微浮动

删除或停用：

- 角色眨眼
- 角色肢体连续摆动
- 炮口旋转
- 复杂 SVG 分层动画
- 高频循环动作

所有动效继续支持 `prefers-reduced-motion`。
