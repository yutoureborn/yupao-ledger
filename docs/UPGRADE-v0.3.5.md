# v0.3.5 升级说明

本次迭代聚焦三个问题：

1. **品牌角标未切换到新角色规范**
2. **移动端仍然像桌面页面直接缩小**
3. **统计页支出分类模块比例失衡，局部信息挤压严重**

## 本次变更

- 侧栏 / 移动端顶部品牌角标更新为新版「大芋头 + 小坦克」联名 SVG 标识
- 首页与通用页头增加移动端专属排布：月份切换、按钮与卡片间距重新设计
- 移动端首页 Hero、摘要卡、发票区、筛选区改为更贴近手机使用习惯的布局
- 统计页改为新的 `stats-grid-v035` 网格：
  - 说明卡整行
  - 趋势整行
  - 支出分类 7 列
  - 预算 5 列
  - 近六个月整行
- 支出分类完整页模块重新调整：
  - 头部信息与摘要指标比例优化
  - 环形图与右侧信息卡宽度重分配
  - 最高分类名称避免挤压成异常换行
  - 分类明细区节奏与金额列宽优化

## 不涉及内容

- 不新增 D1 migration
- 不修改认证逻辑
- 不修改现有账目、预算、发票数据
- 不改 `wrangler.jsonc`
