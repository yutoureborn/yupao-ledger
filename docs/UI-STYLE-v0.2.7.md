# 芋炮小账本 v0.2.7 UI 风格规范

## 1. 设计方向

本版本将界面调整为“奶油手账 + 贴纸标签 + 活页记录”的生活化风格。参考的是手账产品的组织方式，不复制具体第三方界面、插画或素材。

核心关键词：

- 奶油粉白
- 活页纸与标签
- 柔和描边
- 圆角贴纸
- 静态角色插画
- 少量必要动效
- 信息可读性优先

## 2. 色彩

```css
--page: #fff9f5;
--paper: #fffdfb;
--paper-soft: #fff3f0;
--primary: #ee8faf;
--primary-deep: #d96f95;
--peach: #f4b27e;
--lavender: #b69add;
--sage: #a8c996;
--ink: #332638;
--muted: #8d7484;
--line: #ead7df;
```

语义色仍由功能决定，不能仅依靠粉色区分：

- 收入：柔和绿色
- 支出：珊瑚粉橙
- 发票收到：淡紫
- 发票开出：柔和绿色
- 作废：灰色 + 文字状态
- 错误：克制红色

## 3. 页面结构

### PC

- 左侧导航模拟手账侧边标签。
- 主内容使用大张纸卡，避免密集后台表格。
- 一级模块之间保持 20–28px 间距。
- 数据卡可使用胶带、标签、印章等伪元素，但不遮挡正文。

### 移动端

- 纵向内容流。
- 底部导航固定：首页、明细、记一笔、发票、统计。
- 设置通过右上角头像进入，避免底部出现六个入口。
- 卡片左右间距 14–16px，主要点击区域不少于 44px。

## 4. 组件规范

### 卡片

- 圆角 18–24px。
- 1px 柔和描边。
- 极轻阴影，避免玻璃拟态。
- 卡片标题和操作按钮保持同一基线。

### 按钮

- 主按钮使用粉橙渐变或纯主色。
- 次按钮使用白底描边。
- 危险操作不做大面积红色，使用文字和确认框共同表达。

### 表单

- 输入框使用奶油白底和细描边。
- 聚焦状态为主色描边和浅色光环。
- 必填、错误、提示分别使用文字明确说明。
- 发票关联下拉必须明确显示日期、交易名和金额。

## 5. 角色与动效

- 芋头、炮台使用静态 WebP 插画。
- 不再做复杂肢体动画或持续浮动。
- 只保留页面首次出现的淡入、按钮反馈、图表缓动和 Toast。
- `prefers-reduced-motion` 下关闭非必要过渡。

## 6. 图表

- 使用低饱和粉、紫、绿、橙色板。
- 环形图中心只显示本月支出和金额。
- 分类列表始终展示名称、占比、进度和金额。
- 图表不能脱离分类列表单独存在。
- 移动端先图表、后分类列表，禁止横向滚动。

## 7. 验收

- 1366px 和 1920px 下无内容堆叠。
- 360px 移动宽度下无横向滚动。
- 超长分类、发票抬头和对方名称使用省略号或合理换行。
- 200% 浏览器缩放下核心功能仍可操作。
- 角色插画不抢占金额、按钮和表单的视觉优先级。
