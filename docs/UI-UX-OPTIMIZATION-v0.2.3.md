# 芋炮小账本 v0.2.3 PC / 移动端 UI 优化任务列表

> 目标：解决桌面端信息挤压，统一跨端信息层级，同时保持轻量可爱，不增加无意义装饰。

## 1. 截图问题复盘

原“钱花去了哪里”卡片存在：

1. 分类名称被挤成两行。
2. 百分比和金额争抢宽度。
3. 圆环图留白过大，排行榜区域过窄。
4. 单条数据时信息集中在局部，卡片整体失衡。
5. 移动端若沿用同一横向结构，会进一步挤压。

根因是卡片继承页面两列栅格后，内部继续使用不稳定的 flex 布局，没有根据卡片自身宽度响应。

---

## 2. 已完成修改

### P0：支出分类卡片重构

已改为容器响应布局：

```text
PC 宽卡片：圆环图 | 分类排行
窄卡片：圆环图
          分类排行
手机：图标 | 分类名 | 金额
             占比
          进度条
```

桌面排行榜固定为四列：

```text
38px 图标 | 自适应分类信息 | 54px 占比 | 76px 金额
```

完成项：

- 分类名不换行，超长使用省略号
- 百分比右对齐
- 金额固定列宽和等宽数字
- 进度条归属分类信息列
- 圆环和排行榜按 0.68 : 1.32 分配空间
- 使用 Container Query，不依赖整个浏览器宽度
- 卡片不足 620px 时自动改为纵向
- 卡片不足 390px 时改为移动端区域布局

### P1：信息层级调整

- 圆环中心保留“本月支出 + 总金额”
- 右侧优先显示分类名称
- 百分比降为次级信息
- 金额保持强调但不超过总金额层级
- 增加分类数量说明，减少单分类时的空旷感

### P1：拟人角色融入界面

- 安全设置页使用抱锁/盾牌状态
- 成功状态增加金币与星光动作
- 空状态保留抱账本动作
- 预算提醒使用提示牌，不使用爆炸效果

## 5. 动画规范

已实现：

- 芋头呼吸、眨眼、挥手、抱账本轻微起伏
- 玩具炮台眨眼、挥手、炮口观察动作
- 成功时金币/星光出现
- 安全状态显示盾牌与锁
- `prefers-reduced-motion` 下关闭循环和大幅动画

约束：

- 操作反馈：120–220ms
- 页面/卡片进入：180–320ms
- 角色一次性反馈：400–900ms
- 待机循环间隔不少于 3 秒
- 动画仅使用 transform / opacity 为主
- 图表动画不得阻塞按钮和滚动

## 6. 跨端验收尺寸

必须人工检查：

```text
360 × 800   小屏 Android
390 × 844   常见 iPhone
768 × 1024  平板竖屏
1024 × 768  平板横屏
1366 × 768  常见笔记本
1440 × 900  PC
1920 × 1080 大屏 PC
```

验收重点：

- 无横向滚动
- 金额不截断
- 分类名不与百分比重叠
- 弹窗不超出视口
- 手机软键盘不遮住提交按钮
- 图表空状态不塌陷
- 减少动态模式正常
