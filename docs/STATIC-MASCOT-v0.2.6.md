# 芋炮小账本 v0.2.6 静态角色插画规范

## 1. 策略变化

v0.2.6 将角色从“复杂 SVG 动画角色”调整为“高质量静态插画 + 极轻微 UI 动效”。

原因：

- 静态插画更容易完整还原拟人蔬菜参考风格。
- 避免复杂动画造成廉价感。
- 减少首屏计算和维护成本。
- 保持 PC 与移动端画风一致。

## 2. 芋头

定位：元气记账小助手。

视觉要求：

- 主体为明显芋泥紫。
- 不规则根茎轮廓，不使用简单椭圆。
- 两片绿色叶子。
- 大眼高光、轻腮红、完整手脚。
- 常用道具：铅笔、收据、小账本。

应用场景：

- 快速记账
- 空状态
- 保存成功
- 首次使用引导

生产资产：

- `taro-quick.webp`
- `taro-ledger.webp`

## 3. 炮台

定位：生活账本整理管家。

视觉要求：

- 主体苔绿与墨绿。
- 炮管与轮胎为黑灰色。
- 圆润玩具机械造型。
- 保留大眼和轻腮红。
- 炮管用于投影和整理，不表达攻击性。

应用场景：

- 统计分析
- 分类整理
- 预算提醒
- 安全设置

生产资产：

- `cannon-summary.webp`
- `cannon-organize.webp`

## 4. 组合角色

`hero-duo.webp` 用于：

- 首页 Hero
- 登录页视觉区
- 关键欢迎场景

`duo-mini.webp` 用于：

- 加载状态
- 小尺寸品牌场景

## 5. 动效

静态插画只允许：

- 3px 内的低频上下浮动
- 页面进入淡入
- 成功状态短时淡入

减少动态模式下全部关闭。

## 6. 性能

- WebP 格式
- 单张约 5～35KB
- 不依赖外部 CDN
- 按场景懒加载
- Hero 图使用 eager，其余使用 lazy
