# 芋炮小账本 v0.2.7 发票模块说明

## 1. 范围

发票夹记录两类凭证：

1. **我收到的发票**：只能关联支出。
2. **我开出的发票**：只能关联收入。

系统允许先记录发票、暂不关联，之后编辑补充对应收支。

## 2. 字段

- 类型：收到 / 开出
- 状态：正常 / 作废
- 发票号码
- 发票代码（可选）
- 发票抬头或内容
- 开票方 / 客户名称
- 发票金额
- 税额（可选）
- 开票日期
- 关联交易（可选）
- 备注（可选）
- 创建人、更新人、版本与时间

金额按“分”存储，避免浮点误差。

## 3. 关联规则

```text
收到的发票 → 支出
开出的发票 → 收入
```

Worker 会再次校验：

- 交易属于当前家庭。
- 交易未被软删除。
- 收到的发票不能关联收入或转账。
- 开出的发票不能关联支出或转账。

同一笔收支可以关联多张发票；一张发票在当前版本只能关联一笔收支。

## 4. 页面

### 发票夹首页

- 收到 / 开出双 Tab。
- 月份切换。
- 正常 / 作废筛选。
- 已关联 / 未关联筛选。
- 号码、抬头和对方名称搜索。
- 月度张数、金额与已关联数量。

### 新增与编辑

- 根据类型自动切换“关联支出”或“关联收入”。
- 候选交易显示日期、交易标题和金额。
- 保存失败保留用户输入。

### 交易列表

有关联发票时显示：

```text
🧾 N张
```

## 5. 作废与恢复

- 删除操作改为“作废”，不会删除发票或关联交易。
- 作废发票不计入正常发票月度汇总。
- 恢复时保留原关联关系，但用户需要重新确认关联是否仍合适。

## 6. 当前边界

v0.2.7 暂不包含：

- 发票图片或 PDF 附件上传。
- OCR 自动识别。
- 一张发票拆分关联多笔交易。
- 回款、报销、抵扣等复杂税务状态。
- 专业税务申报或会计凭证能力。

后续附件建议使用私有 Cloudflare R2，不应公开暴露文件 URL。
